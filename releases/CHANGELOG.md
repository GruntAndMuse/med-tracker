# What's new — Med Tracker

Plain-language changelog, newest first. The app fetches this file from
GitHub when you tap "Check for Updates".

## v1.0.28 - 2026-10-03
- What's new: see exactly what changed before you update
- Go back to the previous version if a new one ever breaks something (your data is backed up first, automatically)
- Set your own "warn me" threshold per medication — high if refills are slow, low if pickup is same-day
- Expiration dates per refill bottle, with a "grab this bottle first" reminder for the one expiring soonest
- Pick your own reminder sound from the Android system picker
- Backups now save to Downloads → med-tracker-backups, so they're always in the same place
- New "About GruntAndMuse" section: who we are and why there's no ads

## v1.0.26 - 2026-10-03
- Fixed the photo crop tool: corners are grabbable even at the edges, smooth dragging, pinch to zoom
- Reminder settings now confirm when a change is saved

## v1.0.25 - 2026-10-03
- Reminder settings now confirm immediately when a change is saved

## v1.0.24 - 2026-10-03
- Privacy fix: lock-screen notifications show no pill, medication, or dose details — just "Tracker", tap to open
